# Question 2: Revising the Select Query II

**Platform:** HackerRank

**Difficulty:** Medium

**Problem Statement**

Query the NAME field for all American cities in the CITY table with populations larger than 120000.
The CountryCode for America is USA.

### Solution

SELECT NAME
FROM CITY
WHERE UPPER(COUNTRYCODE) = 'USA' AND POPULATION > 120000;

### Explanation

- **Purpose**: Retrieves the names of cities in the USA with a population greater than 120,000.
- **Selected Column**:
  - `NAME`: Selects only the names of the cities.
- **Data Source**:
  - `FROM CITY`: Pulls data from the `CITY` table.
- **Filtering**:
  - `WHERE UPPER(COUNTRYCODE) = 'USA'`: Ensures that the `COUNTRYCODE` matches 'USA' (case-insensitive).
  - `AND POPULATION > 120000`: Further filters the results to include only cities with a population greater than 120,000.
