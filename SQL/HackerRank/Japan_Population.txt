# Question 26: Japan Population

**Platform:** HackerRank

**Difficulty:** Medium

**Problem Statement**

Query the sum of the populations for all Japanese cities in CITY. The COUNTRYCODE for Japan is JPN.

### Solution

SELECT SUM(POPULATION)
FROM CITY
WHERE UPPER(COUNTRYCODE) = 'JPN'

### Explanation

### **Purpose**:
The query calculates the total population of all cities in the `CITY` table that are located in Japan.

### **Query Breakdown**:
1. **Selected Column**:
   - `SUM(POPULATION)`: Calculates the sum of the `POPULATION` column for the cities that meet the filtering condition. This provides the total population of all cities in Japan.

2. **Data Source**:
   - `FROM CITY`: Specifies the `CITY` table as the source of the data.

3. **Filtering Condition**:
   - `WHERE UPPER(COUNTRYCODE) = 'JPN'`: Filters the rows where the `COUNTRYCODE` column (converted to uppercase using `UPPER()`) is equal to `'JPN'`. This ensures the comparison is case-insensitive, so even if the country code is stored as lowercase or mixed case, it will still match.

### **Result**:
The result will be a single value representing the total population of all cities in Japan listed in the `CITY` table.
