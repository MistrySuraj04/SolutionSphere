# Question 22: Revising Aggregations - The Count Function

**Platform:** HackerRank

**Difficulty:** Medium

**Problem Statement**

Query a count of the number of cities in CITY having a Population larger than .

### Solution

SELECT COUNT(NAME)
FROM CITY
WHERE POPULATION > 100000;

### Explanation

### **Purpose**:
The query counts the number of cities from the `CITY` table that have a population greater than 100,000.

### **Query Breakdown**:
1. **Selected Column**:
   - `COUNT(NAME)`: Counts the number of rows where the `NAME` column is not `NULL`. In this case, it counts the number of cities with a population greater than 100,000.

2. **Data Source**:
   - `FROM CITY`: Specifies the `CITY` table as the source of the data.

3. **Filtering Condition**:
   - `WHERE POPULATION > 100000`: Filters the results to include only cities where the population is greater than 100,000.

### **Result**:
The result will be a single value representing the count of cities in the `CITY` table that have a population greater than 100,000.
